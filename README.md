# 磨 — 鬼教官の記録所

**https://aiueo98765.github.io/migaki/**

勉強・鍛錬・浪費・画面時間を記録して、3 日ごとに格付けされる。
教官が傾向を暴き、このままの未来を容赦なく予想する。

鍵も会員登録も要らない。`index.html` を開けば動く。
記録はこの端末の `localStorage` にだけ残り、外には出ない。

```bash
python scripts/serve.py
```

`http://localhost:8765` が開く。`file://` でも概ね動くが、
API キーを使う相談だけは `http://` で出した方が確実。

## 中核の決めごと

### 自己申告をやめた

点になるのは **タイマーを回している間に実際に流れた時間** だけ。

- 画面を離れると自動で止まる（`visibilitychange` / `blur`）。離席の回数も記録に残る。
- 押し忘れた分は手で書けるが「申告」として **50%** しか通らない。
- 申告は **段位に一切積まれない**。書くだけでは強くならない。
- 浪費だけは申告でも割り引かない。引かれる側を自己申告で軽くできたら意味がない。
- 書けるのは **今日と昨日まで**。それより古い日は閉じる。

実測率は「信用度」として符に載る。相手にも見える。

### 極めるほど点が上がる

分類ごとに、実測した累計時間で **段位** が上がる。上がるほど同じ 1 分が重くなる。

| 段位 | 累計 | 倍率 |
|---|---|---|
| 無位 | 0h | ×1.00 |
| 三級 | 3h | ×1.09 |
| 二級 | 8h | ×1.18 |
| 一級 | 16h | ×1.27 |
| 初段 | 30h | ×1.36 |
| 二段 | 55h | ×1.45 |
| 三段 | 90h | ×1.54 |
| 四段 | 150h | ×1.63 |
| 五段 | 240h | ×1.72 |
| 皆伝 | 400h | ×1.81 |
| 極 | 650h | ×1.90 |

さらに連続記録で全体に倍率（60 日で ×1.24）。
目標の 1.5 倍を超えた分も 0.6 倍は通る。頭打ちにしない。

**極み値** ＝ 全分類の段位の合計（上限 60）。符に載って相手と並ぶ。

### 三日裁定

開始日から 3 日ずつを一期として締め、平均で格を付ける。

`F 論外 / E 凡夫 / D 半人前 / C 並の男 / B 芯が通る / A 一目置かれる / S 別格 / SS 怪物`

記録しなかった日は 0 ではなく **負債**（厳しさにより −20 / −40 / −70）として平均に入る。
やらなかった日より、書かなかった日の方が低い。見えない日は直せないからだ。

### スクリーンタイム

**Web ページから端末のスクリーンタイムを自動で読む方法は無い。**
iOS も Android も外に出す口を持っていない。だから手で写す。

- iPhone：設定 → スクリーンタイム → すべてのアクティビティ
- Android：設定 → Digital Wellbeing

上位 3 つで充分。15 秒で終わる。
同じ日に「だらだら」で書いた分は差し引く（同じ時間を二度罰しない）。

### 鬼教官

- **鍵なし**：内蔵の判定が記録を読んで答える。分析・未来予想・相談すべて動く。
- **API キーあり**：本物の Claude（Opus 5.5 / Sonnet 5.5 / Haiku 5.5 を選べる）。
  キーはこの端末にだけ残り、Anthropic 以外には送らない。

未来予想は傾きをそのまま延ばさない。頭打ちさせて、実際に出した点の幅に収める
（傾き × 日数では誰も取らない数字が出るため）。

### 刃（戦績）

積み上げた物が形になる。数字ではなく見た目で分かる唯一の画面。

| 見える物 | 元になる数字 |
|---|---|
| 長さ | 実測した累計時間（対数で伸ばす） |
| 研ぎ・刃文・光沢 | 極み（段位の合計）。鈍ら か 鏡面 か |
| 棟の欠け | 記録しなかった日（直近30日） |
| 染み | 赤字で終えた日 |
| 刃先の焔 | 連続記録 |

`canvas` で毎フレーム描いている。戦績の画面を離れると止まる。

### 追走（今日）

**「今この時刻で、最高の日のお前は何点持っていたか」**

実測セッションには時刻が残っているので、日の中の積み上げを時刻で追える。
今日の曲線（赤）と、最高の日または直近7日平均（金の破線）を同じ時間軸に重ねる。

> 01:56 の時点で、お前は 452 点。最高の日のお前は 582 点だった。
> あの日のお前は 13:45 には今の点に届いていた。12.2 時間ぶん遅れている。

相手は他人ではない。先に走っている自分だ。
手で打った申告には時刻が無いので、この線には乗らない。

### 作戦（教官）

次の3日を組ませる。組まれた指示はそのまま「本日の課業」に金枠で出て、済ませれば点になる。

- 鍵があれば **Claude が JSON で返す**。形を検めてから入れる（days がちょうど3つ、cat は実在する分類 id、min は 0〜600）。壊れていたら内蔵に落とす。
- 鍵が無ければ内蔵が組む。材料は「分析の最上位」「段位が一番近い分類」「良い日の型」。
- **変える点は3日通して一つに絞る。** 並べ立てた計画は必ず崩れる。崩れるのは意志が弱いからではなく、一度に多く変えたからだ。

期が締まった時の裁定も、鍵があれば Claude が書き直す。

### 良い日の型 / 効いている順

- **良い日の型**：上位3分の1の日と下位3分の1の日で、起床・立ち上がり・睡眠・画面・だらだら・実測率などの平均を並べる。差の大きい順。「強い日は何から始めているか」も出す。
- **効いている順**：各要因と点の相関。数字は「その項目が上位1割の日と下位1割の日で、点が何点違うか」。
  一要因が点の散らばり全体より大きく効くはずがないので、そこで頭を押さえてある。
  相関であって因果ではない。要因どうしは絡み合っているので足し合わせてはいけない。両方とも画面に書いてある。

### 符（友達と競う）

サーバーを通さない。`MG1.` で始まる文字列を LINE や X で送り合うだけ。
符には 極み・実測した時間・今期平均・通算平均・最高・連続・信用度 が載る。
相手の実測率が低ければ「この符の数字は、その分だけ割り引いて見ろ」と出る。

### 踏んだ罠

- `scoreTier` の級名に `top` を使うと、上の帯の `.top`（`position:fixed`）と
  クラス名が衝突して点数が画面の隅に飛ぶ。級名は `best` にしてある。
- `deepFill` は既定値が `null` の鍵（`rival` など）で `Object.keys(null)` に落ちる。
  落ちると記録が既定値で上書きされて消えるので、
  読めなかった時は `migaki.v1.broken` に退避して保存を止める。
- `let S = defaults()` と書くと `defaults()` の中の `today()` が TDZ の `S` を触って落ちる。
  先に `let S = null` で器を作ってから代入する。
